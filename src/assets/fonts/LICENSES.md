# Bundled certificate fonts

Used by `src/common/utils/certificate-svg.util.ts` so certificate text renders
on any server, whether or not it has system fonts installed.

- **Liberation Sans / Liberation Serif** (`Liberation*.ttf`): SIL Open Font
  License 1.1, https://github.com/liberationfonts/liberation-fonts
- **DejaVu Sans / DejaVu Serif** (`DejaVu*.ttf`): Bitstream Vera / DejaVu
  license (free to use, copy and redistribute),
  https://dejavu-fonts.github.io/License.html
